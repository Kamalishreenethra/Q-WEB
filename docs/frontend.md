# SignChain Research Dashboard: React + TypeScript + Vite

## 1. Overview & Purpose
Phase 13 delivers a clean, responsive, enterprise-grade cybersecurity research dashboard for SignChain. It provides visual exploration and interactive reporting over the data generated by the scanner, classifier, quantum risk, PQC readiness, dependency graph, and migration prioritization engines.

---

## 2. Architectural Design & Separation of Concerns

> [!IMPORTANT]
> **Visualization-Only Guarantee**:
> The frontend is strictly a presentation and analytics visualization layer. It does NOT compute risk formulas, infer quantum vulnerabilities, generate candidate PQC algorithms, or calculate graph centrality. All intelligence originates directly from the FastAPI backend.

---

## 3. Technology Stack & Directory Structure
- **Framework**: React 18 + TypeScript 5
- **Build Tool**: Vite 5
- **Routing**: React Router DOM v6
- **Iconography**: Lucide React
- **Styling**: Vanilla CSS custom cybersecurity design system (dark mode, crisp contrast, accessible status indicators)

## 4. Navigation & Routes

| Route | Page | Purpose |
|---|---|---|
| `/` | `OverviewPage` | Summary KPI cards, top migration targets, recent scans. |
| `/artifacts` | `ArtifactsPage` | Filterable inventory across X.509, PE, PGP, Sigstore, OCI images. |
| `/artifacts/:id` | `ArtifactDetailPage` | Full profile with signatures, risk breakdown, PQC candidates, blockers. |
| `/certificates` | `CertificatesPage` | Cryptographic public keys, algorithms, curves, and CA flags. |
| `/risk` | `RiskPage` | Transparent quantum risk score distributions and explanations. |
| `/pqc` | `PQCReadinessPage` | `NOT_READY`, `PARTIALLY_READY`, `HYBRID_READY`, `PQC_READY` tracking. |
| `/migration` | `MigrationPage` | Prioritized migration sequence (P1 Critical to P4 Routine). |
| `/graph` | `GraphPage` | Interactive SVG dependency graph of signing relationships. |
| `/scans` | `ScansPage` | Discovery scan history, execution times, artifact & error counts. |
| `/research` | `ResearchPage` | Evaluation of Hypotheses H1–H5 and flat vs. graph prioritization. |

## 5. Running & Building Locally

### Development Mode
```powershell
cd frontend
npm install
npm run dev
# Starts local Vite dev server on http://127.0.0.1:3000 (proxies /api to http://127.0.0.1:8000)
```

### Production Build
```powershell
cd frontend
npm run build
# Compiles TypeScript and packages production bundle into frontend/dist/
```
